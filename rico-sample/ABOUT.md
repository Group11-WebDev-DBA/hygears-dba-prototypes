# Rico's sample PHP app

A minimal frontend and backend Rico made to test that `hygears.sql` works: Dashboard, Roles / Purposes / Categories, People, Attendance, Items & Stock, and Requests, running on the real database.

It isn't part of the final project. It's here as a working reference for the PHP rebuild, next to the design prototypes.

It needs PHP and MySQL, so it can't run on GitHub Pages. To try it, follow Rico's steps in `README.md` (XAMPP: put the files in `htdocs/Hygears`, run `hygears.sql`, start Apache and MySQL, open `http://localhost/Hygears/index.php`).
