# Hygears HQ System (DBA): prototypes

UI prototypes for the internal Hygears HQ system (Database Administration project, Group 11, BSIT 3-2): attendance kiosk at the HQ door, dashboard, attendance log, people and members, items and restocking, borrowing requests, reports and settings.

**Open online:** https://group11-webdev-dba.github.io/hygears-dba-prototypes/

- `BRIEF.md`: the screens and rules every prototype follows, mapped to the schema
- `hygears.sql`: copy of the schema from the hygears-dba repo (source of truth stays there)
- `QA-PROTOCOL.md`: the role-played QA visits

Design directions are being added; this repo starts with the brief and schema.
