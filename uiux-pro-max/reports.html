Attendance per day

Visits and distinct people per day, from the logbook.

dayvisitspeople
2026-11-2466

SQL

SELECT DATE(time_in) AS day,
       COUNT(*) AS visits,
       COUNT(DISTINCT person_id) AS people
FROM attendance
GROUP BY DATE(time_in)
ORDER BY day DESC;

SQL

SELECT p.name AS purpose, COUNT(*) AS visits
FROM attendance a
JOIN purpose p ON p.purpose_id = a.purpose_id
GROUP BY p.name
ORDER BY visits DESC;

Most borrowed items

Approved and completed request lines, summed per item.

SQL

SELECT i.name, SUM(rl.quantity) AS times_borrowed
FROM request_line rl
JOIN item_request q ON q.request_id = rl.request_id
JOIN item i ON i.item_id = rl.item_id
WHERE q.status IN ('approved', 'completed')
GROUP BY i.item_id, i.name
ORDER BY times_borrowed DESC
LIMIT 5;
